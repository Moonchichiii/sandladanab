Integritet & GDPR

Så hanterar vi dina uppgifter.

Kort version: vi använder det du skriver i formuläret för att ringa upp dig om jobbet. Inget annat.

Personuppgiftsansvarig

Sandlådan AB{% if org_number %}, org.nr {{ org_number }}{% endif %}{% if postal_address %}, {{ postal_address }}{% else %}, {{ seat }}{% endif %}. Du når oss {% if show_phone %}på telefon {{ owner_phone_display }} eller {% endif %}via formuläret.

Vilka uppgifter vi samlar in

Bara det du själv lämnar i offertformuläret: namn, telefonnummer, din beskrivning av jobbet och en eventuell bild. Vi sparar inte din IP-adress i något register; den används enbart tillfälligt för att begränsa antalet förfrågningar per minut (skydd mot skräppost) och loggas inte tillsammans med dina uppgifter.

Varför och med vilken rättslig grund

För att kunna återkomma med offert eller boka ett platsbesök, det vill säga för att vidta åtgärder på din begäran innan ett avtal ingås (GDPR art. 6.1 b). Vi använder inte uppgifterna för marknadsföring och skickar inga nyhetsbrev.

Hur länge vi sparar dem

Din förfrågan skickas som e-post till oss och ligger i vår inkorg tills ärendet är avslutat. Blir det inget uppdrag raderas den inom tolv månader. Blir det ett uppdrag sparas uppgifterna som en del av bokföringsunderlaget så länge bokföringslagen kräver (sju år).

Vem som får se dem

Bara vi på Sandlådan AB och den e-postleverantör som förmedlar meddelandet. Vi säljer, hyr ut eller delar inte uppgifter med tredje part.

Kakor och spårning

Webbplatsen använder inga kakor, ingen analys- eller annonsspårning och laddar inga skript, typsnitt eller bilder från tredje part. Det finns därför ingen kakbanner – det finns inget att godkänna.

Säkerhet

Sidan levereras över HTTPS med strikta säkerhetsrubriker (Content-Security-Policy, HSTS, inga tredjepartskällor). Bifogade bilder kontrolleras mot tillåtna filtyper och storlek innan de vidarebefordras.

Dina rättigheter

  • Få veta vilka uppgifter vi har om dig (registerutdrag).
  • Få felaktiga uppgifter rättade.
  • Få uppgifterna raderade när de inte längre behövs för ändamålet ovan.
  • Klaga till Integritetsskyddsmyndigheten (imy.se) om du anser att vi hanterar dina uppgifter fel.
